# hzhz

**Терминальный ИИ-агент на Google Gemini для Linux (CachyOS / Arch).**

Работает прямо в терминале: отвечает на вопросы, выполняет shell-команды, читает и
правит файлы, ищет по коду, обращается к вебу (Google Search) — всё это с
подтверждением опасных действий и стримингом ответа.

```
$ hzhz
hzhz — терминальный агент на Google Gemini • CachyOS/Linux

вы ▸ поставь зависимости для этого проекта и запусти тесты

╭─ инструмент: run_command ─────────────────────────╮
│ $ ls                                              │
╰───────────────────────────────────────────────────╯
Выполнить? [y/n/a] › y
hzhz ▸ В проекте Python, ставлю зависимости через venv ...
```

## Возможности

- 🧠 **Gemini** — модели `gemini-2.5-flash` (быстро) и `gemini-2.5-pro` (точно), переключение на лету (`/model`).
- ⚡ **Стриминг** — текст печатается по мере генерации.
- 🛠 **Инструменты агента**: `run_command`, `read_file`, `write_file`, `edit_file`, `list_dir`, `search_files`, `current_time`, `ask_user`.
- 🔒 **Безопасность** — каждая команда/запись требует подтверждения (y/n/a), разрушительные команды (`rm -rf`, `pacman -R`, `dd`, `systemctl`, `curl | sh` …) спрашиваются **даже** в авто-режиме.
- 🌐 **Google Search** — веб-поиск как инструмент модели (`--search` или `/search`).
- 💬 **REPL и одноразовый режим** — `hzhz` для диалога, `hzhz -p "..."` для скриптов.
- 🌍 Отвечает на языке пользователя (по умолчанию русский), знает специфику CachyOS/Arch (pacman, yay/paru, systemd, Btrfs).

## Установка (CachyOS / Arch Linux)

```bash
git clone <этот-репозиторий> hzhz
cd hzhz
./install.sh
```

Скрипт создаст venv в `~/.local/share/hzhz/venv` и команду `hzhz` в `~/.local/bin`.
Если `~/.local/bin` не в PATH — добавьте в `~/.bashrc` / `~/.zshrc`:

```bash
export PATH="$HOME/.local/bin:$PATH"
```

Ручная установка без скрипта:

```bash
python3 -m venv ~/.local/share/hzhz/venv
~/.local/share/hzhz/venv/bin/pip install .
ln -sf ~/.local/share/hzhz/venv/bin/hzhz ~/.local/bin/hzhz
```

## API-ключ

1. Получите бесплатный ключ: **https://aistudio.google.com/apikey**
2. Передайте его агенту любым способом:

```bash
export GEMINI_API_KEY='ваш_ключ'        # в ~/.bashrc / ~/.zshrc / config.fish
# или
hzhz --key 'ваш_ключ'                    # сохранится в ~/.config/hzhz/config.json (chmod 600)
# или внутри REPL:
/key 'ваш_ключ'
```

## Использование

```bash
hzhz                          # интерактивный REPL
hzhz "как посмотреть логи?"   # сразу вопрос в REPL
hzhz -p "найди баг в main.py" # одноразовый ответ и выход
hzhz -y -p "запусти pytest"   # одноразовый + авто-подтверждение инструментов
hzhz -m gemini-2.5-pro        # другая модель
hzhz --search "что нового в ядре Linux 6.13?"   # с веб-поиском
hzhz -w ~/projects/myapp      # команды выполняются в указанной директории
```

### Флаги

| Флаг | Описание |
|------|----------|
| `-p, --oneshot` | ответить на запрос и выйти (для скриптов) |
| `-m, --model` | модель Gemini (по умолчанию `gemini-2.5-flash`) |
| `-w, --workspace` | рабочая директория для команд |
| `-y, --yes` | авто-подтверждать инструменты (опасные команды всё равно спрашиваем) |
| `--search` | включить Google Search |
| `--key` | указать API-ключ |
| `--no-color` | отключить цвета |

### Команды REPL

| Команда | Действие |
|---------|----------|
| `/help` | справка |
| `/clear` | очистить историю диалога |
| `/model [имя]` | показать/сменить модель |
| `/auto` | авто-подтверждение инструментов вкл/выкл |
| `/search` | Google Search вкл/выкл |
| `/tools` | список инструментов |
| `/key ...` | сохранить API-ключ |
| `/save [файл]` | сохранить диалог в markdown |
| `/quit` | выход |

### Подтверждения

При вызове инструмента, меняющего систему, агент показывает панель и спрашивает:

```
╭─ инструмент: run_command ─────────────────────────╮
│ $ rm -rf build/ dist/                             │
╰───────────────────────────────────────────────────╯
Выполнить? [y/n/a] ›
```

- `y` — выполнить один раз
- `n` — запретить (агент получит отказ и попробует иначе)
- `a` — разрешить и не спрашивать для таких действий до конца сессии
- `q` — выход

Чтение файлов, поиск и время выполняются без вопросов. Разрушительные команды
(`rm -rf`, `dd`, `mkfs`, `pacman -R`, `curl | sh`, `systemctl`, fork-bomb и т.п.)
требуют подтверждения **всегда**, даже с `--yes`.

## Конфигурация

`~/.config/hzhz/config.json` (создаётся автоматически, права 600):

```json
{
  "api_key": "",
  "model": "gemini-2.5-flash",
  "workspace": "",
  "auto_approve": false,
  "web_search": false,
  "command_timeout": 120,
  "temperature": 0.7
}
```

Также читаются переменные окружения:

- `GEMINI_API_KEY` / `GOOGLE_API_KEY` — API-ключ
- `HZZ_TZ` — часовой пояс для `current_time` (по умолчанию `Europe/Paris`)
- `HZZ_CONFIG_DIR` — альтернативный каталог конфигурации

## Инструменты агента

| Инструмент | Назначение | Подтверждение |
|------------|------------|---------------|
| `run_command` | shell-команда (таймаут, обрезка вывода) | да |
| `read_file` | чтение файла с номерами строк | нет |
| `write_file` | создание/перезапись файла | да |
| `edit_file` | точечная замена фрагмента | да |
| `list_dir` | содержимое каталога | нет |
| `search_files` | grep-поиск по регулярному выражению | нет |
| `current_time` | текущие дата/время | нет |
| `ask_user` | уточняющий вопрос пользователю | — |

## Зависимости

- Python ≥ 3.10
- [google-genai](https://pypi.org/project/google-genai/) — официальный SDK Gemini
- [rich](https://pypi.org/project/rich/) — интерфейс в терминале

## Troubleshooting

| Проблема | Решение |
|----------|---------|
| `✗ Не найден API-ключ` | `export GEMINI_API_KEY=...` или `hzhz --key ...` |
| `Ошибка авторизации` | ключ неверный/отозван — возьмите новый на aistudio.google.com/apikey |
| `Превышена квота API (429)` | подождите или смените ключ/модель на `gemini-2.5-flash` |
| `Модель не найдена` | проверьте имя: `/model gemini-2.5-flash` |
| `sudo` не работает из агента | sudo требует TTY с паролем — выполните sudo-команду вручную |
| `hzhz: command not found` | `export PATH="$HOME/.local/bin:$PATH"` |
