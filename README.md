# hzhz

**Терминальный ИИ-агент на Google Gemini для Linux (CachyOS / Arch).**

Работает прямо в терминале: отвечает на вопросы, выполняет shell-команды, читает и
правит файлы, ищет по коду, обращается к вебу (Google Search) — всё это с
подтверждением опасных действий и стримингом ответа.

```
$ hzhz
hzhz — терминальный агент на Google Gemini • CachyOS/Linux

вы ▸ поставь зависимости для этого проекта и запусти тесты

╭─ инструмент: run_command ─────────────────────────╮
│ $ ls                                              │
╰───────────────────────────────────────────────────╯
Выполнить? [y/n/a] › y
hzhz ▸ В проекте Python, ставлю зависимости через venv ...
```

## Возможности

- 🧠 **Gemini** — модели `gemini-2.5-flash` (быстро) и `gemini-2.5-pro` (точно), переключение на лету (`/model`).
- ⚡ **Стриминг** — текст печатается по мере генерации.
- 🛠 **Инструменты агента**: `run_command`, `read_file`, `write_file`, `edit_file`, `list_dir`, `search_files`, `current_time`, `ask_user`.
- 🔒 **Жёсткая защита от разрушительных действий** — опасные команды (`rm -rf`, `pacman -R`, `dd`, `systemctl`, `curl | sh` …) **заблокированы по умолчанию** и выполняются только после разблокировки: пароль опасных команд или флаг `--danger`. `--yes` защиту не обходит.
- 🌐 **Google Search** — веб-поиск как инструмент модели (`--search` или `/search`).
- 💬 **REPL и одноразовый режим** — `hzhz` для диалога, `hzhz -p "..."` для скриптов.
- 🌍 Отвечает на языке пользователя (по умолчанию русский), знает специфику CachyOS/Arch (pacman, yay/paru, systemd, Btrfs).

## Установка (CachyOS / Arch Linux)

```bash
git clone https://github.com/FsbAidol/hzhz.git hzhz
cd hzhz
./install.sh
```

> ⚠️ URL должен заканчиваться на `.git` — это адрес git-репозитория, а не веб-страницы
> (`…/tree/…` — неправильно). Скобки `<>` в команду не входят.

> 🛡 Скрипт `install.sh` из этого репозитория **только** ставит hzhz: venv в
> `~/.local/share/hzhz/venv` и команду `hzhz` в `~/.local/bin`. Он **не** устанавливает
> пакеты, не трогает dotfiles, shell и системные настройки. Если вы видите надпись
> `WARNING: This script is currently untested…` — это НЕ установщик hzhz (первые слова
> нашего скрипта всегда: `==> hzhz: установка из …`).

Скрипт создаст venv в `~/.local/share/hzhz/venv` и команду `hzhz` в `~/.local/bin`.
Если `~/.local/bin` не в PATH — добавьте в `~/.bashrc` / `~/.zshrc` / `config.fish`:

```bash
export PATH="$HOME/.local/bin:$PATH"
```

Ручная установка без скрипта:

```bash
python3 -m venv ~/.local/share/hzhz/venv
~/.local/share/hzhz/venv/bin/pip install .
ln -sf ~/.local/share/hzhz/venv/bin/hzhz ~/.local/bin/hzhz
```

## API-ключ

1. Получите бесплатный ключ: **https://aistudio.google.com/apikey**
2. Передайте его агенту любым способом:

```bash
export GEMINI_API_KEY='ваш_ключ'        # в ~/.bashrc / ~/.zshrc / config.fish
# или
hzhz --key 'ваш_ключ'                    # сохранится в ~/.config/hzhz/config.json (chmod 600)
# или внутри REPL:
/key 'ваш_ключ'
```

## Использование

```bash
hzhz                          # интерактивный REPL
hzhz "как посмотреть логи?"   # сразу вопрос в REPL
hzhz -p "найди баг в main.py" # одноразовый ответ и выход
hzhz -y -p "запусти pytest"   # одноразовый + авто-подтверждение инструментов
hzhz --danger                 # сессия с разблокированными опасными командами
hzhz --set-password           # задать/сменить пароль опасных команд
hzhz -m gemini-2.5-pro        # другая модель
hzhz --search "что нового в ядре Linux 6.13?"   # с веб-поиском
hzhz -w ~/projects/myapp      # команды выполняются в указанной директории
```

### Флаги

| Флаг | Описание |
|------|----------|
| `-p, --oneshot` | ответить на запрос и выйти (для скриптов) |
| `-m, --model` | модель Gemini (по умолчанию `gemini-2.5-flash`) |
| `-w, --workspace` | рабочая директория для команд |
| `-y, --yes` | авто-подтверждать инструменты (**не** обходит защиту опасных команд) |
| `--danger` | разблокировать опасные команды на время сессии |
| `--set-password` | задать/сменить пароль опасных команд и выйти |
| `--search` | включить Google Search |
| `--key` | указать API-ключ |
| `--no-color` | отключить цвета |

### Команды REPL

| Команда | Действие |
|---------|----------|
| `/help` | справка |
| `/clear` | очистить историю диалога |
| `/model [имя]` | показать/сменить модель |
| `/auto` | авто-подтверждение инструментов вкл/выкл |
| `/danger` | разблокировать/заблокировать опасные команды (как `--danger`) |
| `/password [clear]` | задать/сменить (смена спросит старый) или удалить пароль опасных команд |
| `/search` | Google Search вкл/выкл |
| `/tools` | список инструментов |
| `/key ...` | сохранить API-ключ |
| `/save [файл]` | сохранить диалог в markdown |
| `/quit` | выход |

### Защита от опасных команд

Опасные команды — `rm -rf`, `dd`, `mkfs`, `pacman -R`, `pacman -Syu`, `curl | sh`,
`systemctl`, fork-bomb, `parted/fdisk`, `passwd/userdel` и т.п. — **заблокированы по
умолчанию**. Обычное подтверждение `y` их НЕ запускает. Выполняются они только
после явной разблокировки одним из двух способов:

1. **Флаг `--danger`** (или команда `/danger` в REPL) — разблокирует опасные команды
   на время сессии; перед каждым запуском агент всё равно показывает панель с
   командой и спрашивает `y/n/a` (в `-y`/`--yes` — без вопроса).
2. **Пароль опасных команд** — задаётся заранее: `hzhz --set-password` или
   `/password` (хэш PBKDF2-SHA256, пароль в открытом виде не хранится). При
   попытке опасной команды агент скрытно спросит пароль — верный пароль
   разблокирует **одно** это действие.

```
╭─ ⚠ ОПАСНО: run_command ──────────────────────────╮
│ $ rm -rf build/ dist/                             │
╰───────────────────────────────────────────────────╯
⚠ Требуется пароль опасных команд
Пароль опасных команд: ********
```

Отказ агент получает как ошибку и сообщает пользователю, как разблокировать
(`--danger`, `/danger`, `/password`) — без попыток обойти защиту.

`/password clear` удаляет пароль. Смена существующего пароля через `/password`
требует ввода текущего.

### Обычные подтверждения

При вызове инструмента, меняющего файлы, агент показывает панель и спрашивает:

```
╭─ инструмент: write_file ─────────────────────────╮
│ записать main.py (1024 символов)                  │
╰───────────────────────────────────────────────────╯
Выполнить? [y/n/a] ›
```

- `y` — выполнить один раз
- `n` — запретить (агент получит отказ и попробует иначе)
- `a` — разрешить и не спрашивать для таких действий до конца сессии
- `q` — выход

Чтение файлов, поиск и время выполняются без вопросов.

## Конфигурация

`~/.config/hzhz/config.json` (создаётся автоматически, права 600):

```json
{
  "api_key": "",
  "model": "gemini-2.5-flash",
  "workspace": "",
  "auto_approve": false,
  "web_search": false,
  "command_timeout": 120,
  "temperature": 0.7,
  "danger_password_salt": "",
  "danger_password_hash": ""
}
```

Также читаются переменные окружения:

- `GEMINI_API_KEY` / `GOOGLE_API_KEY` — API-ключ
- `HZZ_TZ` — часовой пояс для `current_time` (по умолчанию `Europe/Paris`)
- `HZZ_CONFIG_DIR` — альтернативный каталог конфигурации

## Инструменты агента

| Инструмент | Назначение | Доступ |
|------------|------------|--------|
| `run_command` | shell-команда (таймаут, обрезка вывода) | обычные — с `y/n/a`; опасные — **пароль или `--danger`** |
| `read_file` | чтение файла с номерами строк | без вопросов |
| `write_file` | создание/перезапись файла | с `y/n/a` |
| `edit_file` | точечная замена фрагмента | с `y/n/a` |
| `list_dir` | содержимое каталога | без вопросов |
| `search_files` | grep-поиск по регулярному выражению | без вопросов |
| `current_time` | текущие дата/время | без вопросов |
| `ask_user` | уточняющий вопрос пользователю | — |

## Troubleshooting

| Проблема | Решение |
|----------|---------|
| `✗ Не найден API-ключ` | `export GEMINI_API_KEY=...` или `hzhz --key ...` |
| `Ошибка авторизации` | ключ неверный/отозван — возьмите новый на aistudio.google.com/apikey |
| `Превышена квота API (429)` | подождите или смените ключ/модель на `gemini-2.5-flash` |
| `Модель не найдена` | проверьте имя: `/model gemini-2.5-flash` |
| `sudo` не работает из агента | sudo требует TTY с паролем — выполните sudo-команду вручную |
| `hzhz: command not found` | `export PATH="$HOME/.local/bin:$PATH"` |
| `zsh: Нет такого файла…` при `git clone` | URL должен заканчиваться на `.git`, без `<>` и без `/tree/` — см. «Установка» |
| «ОПАСНАЯ КОМАНДА ЗАБЛОКИРОВАНА» | так и должно быть: разблокируйте `--danger` / `/danger` или задайте пароль `/password` |
| Забыли пароль опасных команд | `/password clear` — или удалите `danger_password_salt`/`danger_password_hash` из `~/.config/hzhz/config.json` |
